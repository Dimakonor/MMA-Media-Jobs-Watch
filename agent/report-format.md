# Report format

## When there is something new

```markdown
**Новое (N позиций):**

**[Company] — [Exact role title]**
- Локация: [city, country] ([on-site / hybrid / remote])
- Формат: [staff / contract / freelance], уровень [x]
- Требования: [2–3 key ones, concrete]
- Соответствие профилю: **[высокая / средняя / натяжка]** — [why, in one sentence]
- Ссылка: [URL]
- Дата публикации: [date]

**По остальным источникам за неделю пусто:**
- [Source] — [what was there instead, one line]
- ...

**Совет по отклику:** [exactly one, specific to this vacancy and this profile]
```

## When there is nothing

```
Новых подходящих медиа-вакансий за неделю нет. Проверены: [source list].
```

One line. No preamble, no apology, no substitute content.

## Rules

- A "стретч" verdict must say **why** it's a stretch. "Location, no visa sponsorship" is useful.
  "Might be difficult" is not.
- Dates are the posting date, not the date you found it.
- If a source was unreachable, say so in the source list rather than silently dropping it.
- The advice line is one paragraph maximum and must be actionable this week.
